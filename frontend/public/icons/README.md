# DocVault PWA Icons

Place your PWA icons here:
- `icon-192.png` — 192×192 px, maskable icon for Android
- `icon-512.png` — 512×512 px, any-purpose icon (splash screen, app store)

You can generate these from any logo using https://realfavicongenerator.net
or https://maskable.app/editor

The icons are referenced in `/src/app/manifest.ts`.
